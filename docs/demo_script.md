## One-line tagline

**Sisi turns WhatsApp into the books, statements, and daily plan for every South African spaza shop.**

---

## Submission description (~150 words)

Sisi is a WhatsApp-first AI bookkeeper for South African spaza shops — the township corner stores that keep communities fed, but still run on handwritten books, memory, and trust. Owners message Sisi the way they already talk: text, voice notes, and photos, in English, isiZulu, Afrikaans, isiXhosa, or mixed slang. Sisi logs sales, reads a handwritten book page and asks Yes/Undo before saving, keeps credit customers with per-debtor statement cards and PDFs carrying the shop logo, drafts gentle reminders, and sends a daily 7pm nudge plus a Sunday snapshot. Tap menus work; free typing still works; one message can chain actions ("sold 2 bread and send Thandi her statement"). Built on Meta models, WhatsApp, Modal, and Turso, Sisi needs no new app — just the chat they already open every day. Demo shop: Bongi's Spaza Shop.

## Recording checklist (before you hit Record)

### Phone / WhatsApp setup
- [ ] Charge phone past 50%; plug in if possible
- [ ] Do Not Disturb / Focus on; silence calls and banners
- [ ] Brightness mid-high and locked; auto-brightness off
- [ ] WhatsApp chat with Sisi open; chat wallpaper plain/dark so cards pop
- [ ] Demo shop already set up: **Bongi's Spaza Shop**, logo loaded, float set, language English (switch once mid-demo)
- [ ] Clean demo data seeded: Sipho, Thandi, Mama Zodwa, Bongani with sensible balances; stock includes bread, milk, airtime, cool drink
- [ ] Pre-stage (do **not** send until the timed cue):
  1. Text: `sold 2 bread to Sipho on credit`
  2. A 4–6s voice note in isiZulu: *"Ngithengise amalitha amabili kaMama Zodwa"* (sold 2 litres to Mama Zodwa)
  3. Clear photo of a handwritten book page (one sale line + one credit line)
  4. Text: `send all debtors their statements`
  5. Text: `sold 2 bread and send Thandi her statement`
  6. Tap **Menu** once so reply/list buttons are warm
- [ ] Have the shop logo image ready if you show setup briefly
- [ ] Screen Recording app ready (iOS Control Centre / Android built-in); mic ON for VO **or** record VO separately in Descript and mute phone mic

### Desktop / edit
- [ ] Record VO in one take if possible (calm, clear, slight township energy — not corporate)
- [ ] Cut dead WhatsApp typing delays; keep real Sisi reply latency under ~3s on screen
- [ ] Burn in soft captions for accessibility (judges watch muted too)
- [ ] End card: `Sisi · WhatsApp bookkeeper for spaza shops` + GitHub public URL + demo number if allowed
- [ ] Export 1080p, H.264, ≤100MB if the portal is picky; keep a 4K master

### Safety
- [ ] No real customer phone numbers, no personal WhatsApp other than the demo chat
- [ ] No API keys, Modal tokens, or `.env` visible in any screen recording
- [ ] Repo must be public before judges click the link

## Judging tips (hackathon)

- The **video is weighted most** — make the logo-on-statement moment and the photo→Yes/Undo moment unmissable.  
- Show **real product latency**, then tighten in edit; do not mock replies.  
- Captions help judges watching muted.  
- Public repo + working `/health` + clean README before you upload.  
- Keep personal Wi-Fi cutoff in mind: export and upload the video **before midnight SAST**.
